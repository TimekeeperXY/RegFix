# RegFix

RegFix 是一个面向 Windows 10/11 重装场景的桌面软件迁移助手，采用“重装前采集、重装后匹配”的方式工作。

## 当前预览版 0.1

当前版本提供：

- 扫描已安装软件清单和开始菜单快捷方式。
- 读取第三方 Windows 服务的部分配置，以及尝试导出默认应用关联清单。
- 可选扫描用户指定目录中的 `.exe` 文件，并记录文件版本信息与 SHA-256。
- 保存、读取带版本号的 `.regfix.json` 迁移包。
- 重装后扫描用户指定的软件目录，按 SHA-256 匹配程序文件。
- 逐项预览并恢复当前用户开始菜单中的快捷方式。
- 为确认匹配的非 MSI 软件，在当前用户“程序和功能”列表中创建卸载显示项；可以撤销 RegFix 自建项。
- 在管理员确认后重建受支持的 Win32 服务基本配置；服务保持停止，并可撤销 RegFix 自建且已停止的服务。
- 将采集到的文件类型/协议登记为当前用户的默认应用候选；不更改当前默认选择，可以撤销 RegFix 自建候选。
- 提供打开 Windows 默认应用设置的入口。

迁移包为未加密的可读 JSON，会包含软件路径、卸载命令、快捷方式参数和服务账户名称；不会保存密码或完整注册表 hive。请保存到不会被重装的分区或移动硬盘，并妥善保管。

## 当前限制与安全边界

- “程序和功能”显示项只按当前用户创建，不能替代 MSI 数据库，也不恢复安装器的修改/修复能力；MSI 软件需使用原安装包或厂商安装器修复。
- 服务只支持 Win32 自有进程/共享进程及 Windows 内置服务账户；不重建驱动、服务专有注册数据、账户密码或复杂依赖。创建与撤销均需管理员权限；服务保持停止，运行中的服务需先手动停止才能撤销。
- 文件关联只登记应用候选，不更改 Windows 默认应用；用户需在 Windows 设置中确认。
- 未采集的软件专有注册项、COM 组件、驱动、凭据、许可证、计划任务和用户配置不能保证恢复。
- 补充扫描目录会递归读取其中的可执行文件元数据并计算哈希；请只选择可信的软件目录。扫描过程不会启动程序。
- 可执行文件恢复路径必须位于用户明确选择的扫描目录中，并匹配迁移包中的 SHA-256；无法唯一匹配时需人工处理。
- 这是预览版。恢复前会逐项确认；没有成熟规则的软件仍需运行原安装程序修复或重新安装。

## 开发运行

需要安装 .NET 8 SDK 和 Windows Desktop Runtime。

```powershell
dotnet run --project .\RegFix\RegFix.csproj
```

生成无需目标电脑预装 .NET 的 Windows x64 单文件版本：

```powershell
dotnet publish .\RegFix\RegFix.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o .\artifacts\RegFix-win-x64
```
